# Day 05 - Pet Adoption Page

## 📌 Project Overview

This is my Day 05 project in the **100 Days Web Development Challenge**.

I created a Pet Adoption Page using HTML and CSS. The project displays pet cards with images, descriptions, and adoption buttons in a responsive layout.

## 🚀 Technologies Used

* HTML5
* CSS3
* Flexbox
* Media Queries

## 📚 Concepts Practiced

* Flexbox Layout
* Card Design
* Hover Effects
* Box Shadow
* Border Radius
* Responsive Design
* Media Queries

## ✨ Features

* Pet Adoption Cards
* Pet Images
* Pet Descriptions
* Adopt Me Button
* Responsive Layout
* Hover Animation
